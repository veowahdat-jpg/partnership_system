# سیستم مدیریت شراکت - فروش و سرویس

نسخه حرفه‌ای وب با یوزرنیم و پسورد جداگانه برای هر شریک.

## ویژگی‌ها

- ورود امن با نام کاربری و رمز عبور
- ۴ کاربر پیش‌فرض: ادمین + ۳ شریک
- بخش فروش مواد (ثبت فروش، موجودی خودکار، سود)
- بخش سرویس (مشتریان + پرداخت‌ها + مشخص کردن کدام شریک پول گرفته)
- مصارف مشترک دفتر + برداشت شخصی + مصرف شخصی قابل جبران
- محاسبه خودکار تقسیم سود ماهانه
- لاگ کامل فعالیت‌ها (فقط ادمین می‌بیند)
- رابط کاملاً فارسی و راست‌چین
- ریسپانسیو (موبایل و دسکتاپ)

## نصب و اجرا (روی کامپیوتر خودتان)

### پیش‌نیاز
- Python 3.8 یا بالاتر

### مراحل

```bash
# ۱. وارد پوشه پروژه شوید
cd partnership_system

# ۲. نصب وابستگی‌ها
pip install -r requirements.txt

# ۳. اجرای برنامه
python app.py
```

سپس مرورگر را باز کنید و به آدرس زیر بروید:

**http://127.0.0.1:5000**

## کاربران پیش‌فرض

| نقش       | نام کاربری | رمز عبور  |
|-----------|------------|-----------|
| ادمین     | admin      | admin123  |
| شریک ۱    | partner1   | p1123     |
| شریک ۲    | partner2   | p2123     |
| شریک ۳    | partner3   | p3123     |

**حتماً بعد از اولین ورود رمزها را تغییر دهید.**

## نحوه استفاده آنلاین برای همه شرکا

### روش ۱: اجرا روی یک کامپیوتر در شبکه محلی
اگر همه در یک دفتر هستید، روی یکی از کامپیوترها اجرا کنید و بقیه با IP آن کامپیوتر وارد شوند:
```
http://192.168.x.x:5000
```

### روش ۲: استقرار رایگان روی اینترنت (پیشنهادی)

می‌توانید روی سرویس‌های رایگان مثل **Render.com** یا **Railway.app** مستقر کنید تا همه از هر جایی با اینترنت دسترسی داشته باشند.

مراحل کلی Render:
1. اکانت رایگان در render.com بسازید
2. New → Web Service
3. ریپازیتوری گیت‌هاب پروژه را وصل کنید (یا مستقیم آپلود)
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `python app.py`
6. بعد از دیپلوی، لینک عمومی به شما داده می‌شود

## نکات امنیتی

- در محیط واقعی `app.secret_key` را تغییر دهید.
- رمزهای پیش‌فرض را فوراً عوض کنید.
- برای استفاده جدی، روی HTTPS مستقر کنید.
